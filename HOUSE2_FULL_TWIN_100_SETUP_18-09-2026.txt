MOT LAN TRUOC KHI BAT FULL TWIN
1. Cloudflare account phai co Workers Paid; Containers khong hoat dong tren Free.
2. Worker Builds production phai dung deploy command co wrangler deploy (khong dung versions upload).
   De dam bao dependency cua Worker duoc cai, dat Deploy command:
   cd cloudflare-backup && npm install --no-audit --no-fund && npm run deploy
3. Giu cac secret hien co, dac biet KBL_BACKUP_SYNC_SECRET.
4. Tao R2 S3 API token quyen Object Read + Write cho bucket kbl-backup-media va them 3 Secret vao Worker:
   KBL_R2_ACCOUNT_ID
   KBL_R2_ACCESS_KEY_ID
   KBL_R2_SECRET_ACCESS_KEY
5. Dong goi .env House 1 bang:
   node scripts/build-house2-env-bundle.js .env
   Thu muc data/.house2-secrets nam trong data/ da duoc gitignore va TUYET DOI KHONG commit.
   Them cac file KBL_HOUSE2_ENV_BUNDLE_1... vao Cloudflare Worker Secrets theo README sinh ra.

PLANNED TENTEN MAINTENANCE - KHONG CO KHOANG REPLAY WRITE MO HO
Truoc khi bao tri, goi POST direct Worker /api/failover/activate voi header x-kbl-sync-secret.
Endpoint nay prewarm Container truoc, sau do latch tat ca traffic sang House 2.
Khi latch active, ca GET va WRITE deu di thang House 2.

UNPLANNED OUTAGE
- GET/HEAD: Worker tu latch va replay sang House 2.
- WRITE dang bi timeout o dung khoanh khac House 1 sap: Worker KHONG replay cung write sang House 2 de tranh duplicate don/thanh toan. No bat House 2, tra retryOnHouse2=true; retry 1 lan se chi vao House 2.

FAILBACK AN TOAN
1. De House 1 khoi dong lai nhung CHUA clear latch.
2. POST /api/failover/sync-back nhieu lan den syncBackState.stable=true.
   He thong copy file moi/sua va cung xoa tren primary nhung file da bi xoa trong House 2.
3. Restart Node app tren TENTEN de load state vua sync ve.
4. POST /api/failover/clear voi confirmPrimaryRestarted=true.
5. Kiem tra x-kbl-served-by quay lai tenten-via-cloudflare.
