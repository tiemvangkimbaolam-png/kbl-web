KBL POS THƯƠNG MẠI 2.4.1 - KHÔNG KHÓA - GOOGLE SHEET
=========================================================
- Không cần mã kích hoạt / Machine ID.
- Có tự động lấy giá Google Sheet BK/ASK qua Relay theo cấu hình; không nhúng token bí mật mặc định.
- Giữ đầy đủ Thu Mua, Kho/Tem, Bán/Đổi, Cầm Đồ Pro, Chành, AI/OCR, VNeID/Remote, đối chiếu, báo cáo, website/bảo hành/thành viên.
- Mã sản phẩm cố định; xóa món không dồn mã. Có đổi mã tem hàng hiện tại để in lại.
- Trợ lý thiết bị: tự dò máy in Windows, ghi nhớ máy in tem/giấy, tự dò nhiều chuẩn cân serial phổ biến.
- Dữ liệu nằm ngoài thư mục cài đặt, tự backup hằng ngày; có Sao lưu ngay, Khôi phục và Mở thư mục dữ liệu.
- QR/tem lõi có bộ tạo cục bộ để vẫn tạo được khi mất Internet.

Chạy mã nguồn: npm install && npm start
Đóng gói Windows: npm install && npm run dist

Ban UI v5 2.4.2: du lieu rieng, khong tu sao chep du lieu tu app khac.
